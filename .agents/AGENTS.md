# Regras do Projeto — TechControl

## Leitura Obrigatória do Manifesto de Desenvolvimento

Antes de realizar qualquer tarefa, auditoria, análise, refatoração, implementação ou evolução no sistema TechControl, é **OBRIGATÓRIO** consultar e seguir na íntegra as diretrizes do manifesto de desenvolvimento localizado em:
[MANIFESTO.md](file:///c:/techcontrol/Techcontrolv1-main/MANIFESTO.md)

### Princípios Chave a Garantir:
1. **Compreensão & Causa Raiz:** Nunca aplicar soluções paliativas ou genéricas. Sempre investigar a causa raiz antes de modificar arquivos.
2. **Uso Completo de Skills:** Identificar e combinar automaticamente todas as skills do repositório necessárias para cada tarefa.
3. **Experiência do Usuário & Homologação:** Validar interações como um usuário real navegando pela aplicação.
4. **Qualidade & Sincronização:** Garantir build sem erros, estabilidade de cache/dados, documentação atualizada e commit/push no GitHub ao concluir.
